▶ Run the demo yourself (Node 18+)

git clone https://github.com/dragunxwho13/Upgrade-Pilot && cd Upgrade-Pilot
npm install

:: scan the frozen legacy app — watch every removed API light up
node tool\cli.js scan --path ./sample-app-legacy

:: generate the risk-scored migration plan
node tool\cli.js plan --path ./sample-app-legacy

:: verify the upgraded app — 12/12 green
cd sample-app && npm test

🤖 The six-subagent crew

  • Scanner — maps every deprecated/removed API usage, file & line precision
  • Librarian — reads real migration guides (document understanding) → rule base
  • Planner — risk-scored migration plan tailored to the codebase
  • Codemod Crew — one parallel subagent per package
  • Verifier — upgrades the manifest, runs tests, iterates to green
  • Scribe — release notes, PR description, migration dossier
